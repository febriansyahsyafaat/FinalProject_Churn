# Bank Customer Churn Prediction

Final Project - Machine Learning

## Installation

```bash
pip install -r requirements.txt
```

## Usage

### Run Streamlit
```bash
streamlit run src/streamlit_app.py
```

### Run API
```bash
uvicorn src.api:app --reload
```

## Model Performance
- Accuracy: 84%
- F1-Score: 61%
- ROC-AUC: 85%
